**Soli** is a thought experiment.

The thought: **What might music streaming look like if it was built for musicians rather than to exploit them?**

This is the experiment bit - an [open source](https://github.com/gonzo-engineering/soli), not-for-profit music streaming network with fair, transparent remuneration.

How hard can it be?
